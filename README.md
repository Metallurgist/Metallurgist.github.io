# Professional Engineering Portfolio

Static, responsive portfolio built for GitHub Pages.

## Deploy
1. Create a public GitHub repository named `YOUR_USERNAME.github.io` (replace YOUR_USERNAME with your actual GitHub username).
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. In Settings > Pages, choose Deploy from a branch, `main`, `/ (root)`, and Save.
4. Visit `https://YOUR_USERNAME.github.io/` after GitHub Pages finishes deploying.

## Before sharing
- Replace the placeholder email address and LinkedIn link in `index.html`.
- Verify all experience claims and add company names/dates only if accurate.
- Add a resume link only after uploading a public-safe PDF.
- Use synthetic or sanitized data for project demonstrations.
